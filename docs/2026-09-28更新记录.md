# 2026-09-28 本机更新记录

## 改动

- 检索数据库与正文运行副本移入 Docker 命名卷，源数据只读挂载；应用代码放入镜像。
- 增加默认列表排序及相关性索引、统计缓存、短词 AI 的词边界匹配；转义 LIKE 通配符。
- 固定基础镜像，在容器内构建索引并校验 FTS；保留旧运行版本，可指定版本回退。
- PDF 筛选依据实际可用文件，支持 HTTP Range、HEAD 和 ETag。原件未提供时不再显示无效按钮。
- 待 OCR 与“文件为空”分开显示。页面压缩头部，正文优先，审核信息折叠；支持查询链接、前进后退、取消过期请求及窄屏折叠筛选。
- 对明确包含导航提示的摘要暂不展示，保留原始摘要供复核；规范常见国家同义名称和语言编码。
- 合并主 CSV 中三组内容完全一致的重复列；存在冲突时清理脚本会中止，不会选一列覆盖另一列。
- 采集正文先写入独立待审核目录；PDF 超过提取页数上限时明确报错，不把前 50 页当作完整提取。
- 更新恢复验证和数据清单。Git 不再跟踪可重建的 `viewer/policy_search.db`，本地文件没有删除。

## 实测

同一台 Windows / Docker Desktop 机器。旧版每个接口 3 次，新版预热后连续 30 次；均在容器内访问本地 HTTP 服务。不是长期压力测试，也不代表互联网访问延迟。

| 接口 | 旧版中位数 | 新版中位数 | 新版 p95 |
|---|---:|---:|---:|
| 默认相关政策列表 | 1,724 ms | 1.43 ms | 2.20 ms |
| 统计与筛选项 | 1,762 ms | 0.83 ms | 1.45 ms |
| 短词 AI 搜索 | 1,897 ms | 31.14 ms | 33.01 ms |
| 全库第 500 页 | 1,512 ms | 1.77 ms | 2.34 ms |

4 个默认检索同时发起：旧版每个约 3.17 秒，新版每个约 13 ms、总耗时约 14 ms。AI 短词搜索同时修正了匹配规则，因此前后结果数量不要求相同。

复测命令：`docker exec ai-policy-viewer python scripts/benchmark_viewer.py`。

## 验证结果

- 25 项回归测试通过，包含缺失原件、GB 45438-2025 待 OCR、PDF 分段和缓存、隔离正文、索引完整性及 CSV 冲突保护。
- 全量 10,547 条记录的正文编号、位置和字数通过核对；源 CSV 与 JSONL 的 SHA256 通过核对。
- 容器 SQLite 3.40.1 下 FTS 完整性检查通过。
- 浏览器检查了首屏、标准 PDF 入口、OCR 提示、页面错误及 390px 窄屏筛选。
- Python 语法、JavaScript 语法、HTML 正文容器提取样例检查通过。

## 仍需数据维护的事项

当前本机可访问 418 份原件，其中 PDF 349 份；没有自动补齐其余原件。待 OCR 文件尚未执行 OCR，含噪声摘要暂时隐藏，不等于已重新提取完成。语义上可能混入其他文档的记录仍需要按来源复核，不能仅靠本次规则清理认定全部正文正确。

完整 CSV / JSONL 仍按项目既有规则在仓库外分发。本次更新 GitHub 代码和中文补充材料，没有同步发布 Hugging Face 完整数据包。`dataset_manifest.json` 对应本次本地验收版本，旧数据包与其不一致时验证应报错。
